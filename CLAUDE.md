## Code style

- Private data members are prefixed with an underscore (e.g. `_camera`, `_currentAmmo`). Protected members and constants are not.
- In header files, leave a blank line between every entry (methods and members) so there is room for documentation.
- Constants-only headers (`GameConstants.h`, `AssetConstants.h`) keep their grouped layout.
- Source files use CRLF line endings; keep them when editing or creating files.
