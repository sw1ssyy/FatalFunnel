# TopDownShooter
- Don't build the game after changes, let me test them.

## Learning mode
This is a learning project. For features I mark as 'I want to build this myself' (e.g. vision cone, fog of war),
give design guidance, pseudocode, or raylib API pointers. 
If you write code, please explain it with short comments so that I can learn.
If you need, add example calculations in the comments. 

## Code style

- Private data members are prefixed with an underscore (e.g. `_camera`, `_currentAmmo`). Protected members and constants are not.
- In header files, leave a blank line between every entry (methods and members) so there is room for documentation.
- Constants-only headers (`GameConstants.h`, `AssetConstants.h`) keep their grouped layout.
- Source files use CRLF line endings; keep them when editing or creating files.

## Ask questions if needed
If you are unsure about anything, please ask questions before starting any work.

## Something you need me to do
If there is anything you need me to do, please tell me and don't try and do it yourself.
